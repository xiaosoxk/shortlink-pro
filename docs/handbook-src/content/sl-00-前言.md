# 前言：这本手册怎么用

本手册为 ShortLink Pro 项目（短链接全栈服务）准备，与 elab-agent 手册同一规格：真实代码、设计原理、踩坑实录、速答与演示话术。该项目已开源（github.com/xiaosoxk/shortlink-pro），38 个 pytest 用例全部通过，并完成过真实压测：1200 次并发跳转、吞吐 220 req/s、限流器在限额处精确熔断（654 放行 / 546 拒绝）。

使用方法：第 1 章的电梯陈述与跳转时序图必须滚瓜烂熟；第 2 章按模块精读，每个模块都练"先说结论、再展开原理"；第 3 章的六个坑是本机调试的真实记录，是证明代码归属的最强证据；面试前最后过一遍第 4 章速答清单与演示话术。书中代码均摘自仓库最终版本，可直接对照阅读。[[PB]]
