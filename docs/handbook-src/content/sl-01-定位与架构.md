# 第1章 项目定位与架构

## 1.1 三十秒电梯陈述（背下来）

ShortLink Pro 是一个短链接全栈服务：FastAPI 全异步 + SQLAlchemy 2.0 async + 可选 Redis。核心链路是"注册登录→生成短码→302 跳转→点击统计→实时推送→生成报告级数据"。它的价值不在业务本身，而在于把高级面试的所有考点做进了同一个可运行的系统：手写 HS256 JWT（含 alg 混淆防御）、PBKDF2 密码哈希、雪花 ID 加 Base62 短码、令牌桶限流（内存版与 Redis Lua 原子版）、cache-aside 缓存加负缓存防穿透、SET NX EX 分布式锁加 Lua 校验释放、点击埋点的生产者消费者批写、WebSocket 房间制实时推送、手写纯 ASGI 中间件、ContextVar 链路日志、Prometheus 文本指标、优雅停机。38 个测试全部通过，压测 220 req/s 且限流器在限额处精确熔断。

一句话定位：不背八股，把八股全部写进一个能跑的服务里。

> 追问：为什么选短链接？答：它是系统设计面试的经典题（发号器、缓存、热路径、统计），同时业务足够简单，能把全部复杂度留在"工程考点"上——换成电商或博客，考点密度会大幅下降。

## 1.2 架构与数据流

```
浏览器 ──HTTP──> RequestContext 中间件（request_id/访问日志/指标，最外层）
                    RateLimit 中间件（令牌桶，按 IP，命中 429 短路）
                        FastAPI 路由 /api/auth/* /api/links/* /{code} /ws/links/{code}
                            │
                    LinkService（业务）：cache-aside 读缓存→miss 查库→负缓存防穿透
                            │                            │
                    MemoryCache/RedisCache      analytics.record() → asyncio.Queue
                    （策略模式切换）                      │
                                                消费者任务 + 定时批写任务
                                                （executemany + 计数 UPDATE）
 WebSocket 房间（仅链接主人可订阅）<── 广播点击 ── 跳转路径触发
```

热路径设计是全项目最重要的一笔：一次 302 跳转只做"查一次缓存（命中则零 SQL）+ 一次 put_nowait（微秒级）"，数据库写入完全异步化。这就是压测能到 220 req/s 的原因。

## 1.3 一次跳转请求的完整时序（白板必画）

```
GET /abc123
 → RequestContext: 生成 request_id（uuid hex 12 位）→ ContextVar 注入
 → RateLimit: IP 令牌桶取一币（redirect 桶 600/分钟），不足直接 429
 → 路由 redirect(code)
 → LinkService.resolve:
     cache.get("link:abc123")
     ├─ 命中负缓存哨兵 → 404（不查库，防穿透）
     ├─ 命中数据 → 校验 is_active/expires_at
     └─ miss → SELECT → 回填缓存（TTL 300s）或负缓存（TTL 30s）
 → analytics.record(): 队列 put_nowait（满了丢弃并计数，绝不反压跳转）
 → ws.broadcast_click(): 推给订阅了该短码的主人
 → 302 RedirectResponse（no-store，防浏览器缓存干扰统计）
```

## 1.4 技术选型表（如实回答"为什么"）

| 组件 | 选型 | 一句话理由 |
|---|---|---|
| 框架 | FastAPI | 原生 async + 类型注解驱动的校验与 OpenAPI 文档 |
| ORM | SQLAlchemy 2.0 async | 异步引擎 + session 工厂； expire_on_commit=False 防惰性 IO |
| 数据库 | SQLite（demo）/ Postgres（生产） | 零依赖可演示，连接串一行切换 |
| 缓存/锁/限流 | 自实现双后端 | Redis 可选：有则 RedisCache/Lua 版，无则内存版降级 |
| 认证 | 手写 JWT | 能对着字节讲清结构；防 alg 混淆 |
| 测试 | pytest + httpx ASGITransport | 进程内跑完整 ASGI 栈，不启动服务器 |
