# docs/ 目录说明与制作指南

本目录包含项目面试讲解手册及其全部制作源文件，可独立复现。

## 目录结构

```
docs/
├── ShortLink Pro项目面试讲解手册.docx  # 成品手册（Word，约 18 页）
├── 制作指南.md                          # 本文件
└── handbook-src/                        # 手册制作源文件（可完整复现）
    ├── content/                         # 手册正文（Markdown，5 个章节文件）
    │   ├── sl-00-前言.md
    │   ├── sl-01-定位与架构.md
    │   ├── sl-02-核心模块.md
    │   ├── sl-03-踩坑实录.md
    │   └── sl-04-速答与演示.md
    ├── spec-sl.json                     # 手册规格：章节清单 + 封面标题/副标题/元信息
    ├── generate.js                      # Markdown -> docx 生成器（Node + docx 包）
    ├── add_toc_placeholders.py          # 目录占位符注入（Word 打开前可读）
    ├── fix_toc_dup.py                   # 首条目录去重 + 页码缓存修补
    ├── patch_pagenum.py                 # 页码域修补（罗马/阿拉伯分段，WPS 兼容）
    ├── postcheck.py                     # 生成质量自检（9 项规则）
    └── package.json                     # Node 依赖声明（docx）
```

## 一、环境准备

- Node.js 18+（生成器用），Python 3.11+（后处理脚本用）；
- 后处理脚本依赖 defusedxml：`pip install defusedxml`（若缺）；
- 可选：LibreOffice（用于转 PDF 预览）。

## 二、重新生成手册（完整流水线）

```bash
cd docs/handbook-src
npm install docx                     # 首次需要
node generate.js spec-sl.json        # 1) 生成 docx 到仓库根目录

python add_toc_placeholders.py "../../ShortLink Pro项目面试讲解手册.docx" --auto   # 2) 注入目录条目
python fix_toc_dup.py       "../../ShortLink Pro项目面试讲解手册.docx"             # 3) 目录首条去重
python patch_pagenum.py     "../../ShortLink Pro项目面试讲解手册.docx"             # 4) 页码域修补（封面无页码/前言罗马/正文阿拉伯）
python postcheck.py         "../../ShortLink Pro项目面试讲解手册.docx"             # 5) 质量自检，须 9/9 通过
```

在 Word/WPS 中打开成品后，右键目录选择"更新域"即可刷新为精确页码。

要改手册内容：编辑 `content/` 对应 md（`#`=章、`##`=节、`###`=小节，`> `为"追问"标注，
``` 代码块，| 表格），改完从第 1) 步重跑。要改封面标题/元信息：改 spec-sl.json。

## 三、项目环境搭建与测试

```bash
# 仓库根目录
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements.txt      # 含 sqlalchemy[asyncio]，勿改成裸 sqlalchemy
python -m pytest -q                  # 38 个用例，秒级，不启动服务器也不依赖 Redis
python -m uvicorn app.main:app --port 8000    # 启动服务
python scripts/demo.py               # 另开终端：并发压测演示（含限流 429 分布）
```

Redis 可选：`SL_REDIS_URL` 留空时缓存/限流/锁自动降级内存实现；
`docker compose up` 可一键拉起 app + Redis。

## 四、服务体验入口

- 控制台（前端）：http://127.0.0.1:8000
- 接口文档：http://127.0.0.1:8000/docs
- 健康检查与指标：/health、/metrics（Prometheus 文本格式）
